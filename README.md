# Sistema de Monitoramento de Máquinas e Servidores

## Sobre o projeto
Desenvolvi este projeto em Python com o objetivo de praticar lógica de programação em uma situação relacionada à infraestrutura de TI.

Minha ideia foi simular um sistema de monitoramento de servidores, permitindo acompanhar informações de utilização de CPU e memória e identificar possíveis situações de alerta.

## Funcionalidades
- Cadastrar servidores.
- Consultar servidores cadastrados.
- Informar o percentual de utilização de CPU e memória.
- Atualizar os dados dos servidores.
- Identificar situações normais, de alerta ou críticas.
- Gerar relatórios gerais.
- Excluir servidores cadastrados.

## Conhecimentos utilizados
Python, listas, estruturas condicionais (`if`, `elif`, `else`), laços de repetição (`while`, `for`) e operadores de comparação.

## Como executar
Execute o arquivo Python do projeto em um ambiente com Python 3 instalado.

**Observação:** O sistema é uma simulação acadêmica. Os dados de CPU e memória são informados manualmente, sem monitoramento automático de máquinas reais.
